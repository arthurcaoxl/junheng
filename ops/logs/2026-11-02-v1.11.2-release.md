## 发布背景

- 移动端/PC 端实机测试反馈：打卡页日期时间轴看不出可滑动、浅色 Header 上“绑定邮箱”几乎不可读、PC 矮窗口下 Hero 大标题被固定导航遮挡。

## 发布内容

- 日期时间轴横滑（`8b62626`）：`.day-tabs` 由 21 列 grid 改为 flex 横滑，隐藏原生滚动条，右侧 44px 渐隐遮罩暗示可滑动；用 `button:last-child { margin-right }` 而非容器 `padding-right`，规避“部分浏览器横向滚动不计尾部 padding”导致滑到底最后一天被渐变吃掉的坑。
- Header 胶囊对比度（`8b62626`）：按 `data-active-theme` 作用域切换——浅色（米白）Header 下“绑定邮箱/用户中心”胶囊改深林绿，深色 Header 保持荧光绿；顺带修复 `.is-synced` 胶囊在浅底隐形的历史潜伏 bug。
- Hero 遮挡修复（`8b62626`）：根因是 `align-items: center` 在内容超出 100svh 时的非安全对称溢出，并非 padding 不足；改为 `align-items: start` + 子项 `margin-block: auto` 的“安全居中”模式——空间充裕时视觉不变，矮视口时内容从 Header 之下开始向下溢出，绝不遮挡。
- 行动指令文案（`842e227`）：用户中心“继续打卡”→“继续记录今日体重与腰围”。
- 附带排查结论：右下角 Kimi 浮标经查证非项目代码（发布产物 HTML 无任何注入脚本），确认为托管平台运行时注入，转由平台后台处理。
