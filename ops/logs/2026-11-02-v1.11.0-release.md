## 发布背景

- 指标库 2 上线：用目标进度率、7 日移动平均线和高情商定性评价替代干巴巴的差值数字，强化用户目标感与坚持动力。
- 数据合规前置：为后续平台研究建立“勾选一句话 + 协议超链接”的行业标准授权形态。

## 发布内容

- `utils/metrics.ts` 三个防御性纯函数：`calculateTargetProgress`（`initial === target` 返回 `null`，结果取整并截断 0–100，防浮点溢出与除零）；`calculate7DayMovingAverage`（7 日滑动平均趋势）；`getSmartFeedback`（严格 6 分支，数据不足 2 条返回 `null`，文案克制温暖）。
- BMI 目标差距可视化：手写 CSS 圆角进度条（深灰轨道 + 荧光绿 `#a3e635` 填充，`width 0.5s ease-in-out` 平滑过渡），替代纯文字差值。
- BMI 折线图接入 7 日均线（虚线与每日实线区分）。
- `ConsentDialog` 数据授权弹窗：默认不勾选、未勾选置灰 + “请先勾选同意”轻提示、遮罩 `backdrop-filter: blur`、《用户服务协议》与《隐私政策》超链接。
- 新增 `/terms`、`/privacy` 静态路由（首版排版；PC 端容器与返回按钮在 v1.11.1 完善）。
- Supabase `checkin_sync` 表新增 `consent_granted boolean`、`consent_at timestamptz` 两列（SQL Editor 已执行，历史数据零影响）。
- 打卡入口与首页按钮文案微调（“开启 21 天脂代谢记录 →”等），老测试同步兼容。
