## 内容

### 跨设备数据同步（feature/supabase-sync）

1. Supabase 匿名登录起步 + 邮箱 OTP 绑定升级，本地优先、云端覆盖式备份
2. 打卡页同步 UI 全链路：顶部状态胶囊、表单引导、底部状态栏、绑定/换设备弹窗、连续打卡软引导
3. QQ 邮箱 SMTP + OTP 纯文本模板（防预取、6–8 位动态适配）、60 秒重发冷却与 429 限流提示
4. storage-v3 契约零改动；Vitest 全局 Mock 隔离，测试基线零侵入

### 管理员统计模块（feature/admin-checkin）

1. `camp_admins` 邮箱白名单 + `checkin_sync` 管理员只读 RLS + `admin_checkin_overview()` RPC（数据库侧鉴权，仅 anon key 前端可用）
2. 管理员邮箱 OTP 登录，路径 `/admin/check-in`（含静态深链）
3. 数据看板：KPI 卡（总人数/绑定率/今日打卡/平均体重变化）、recharts 体重腰围折线 + 打卡人数柱状图、D1–D21 明细表、快捷筛选（未绑定/连续 2 天未打卡）、脱敏 CSV 导出
4. 营员下钻满宽弹窗三 Tab：数据明细、个人趋势（复用前台 RecordTrends）、打卡海报（复用 createRecordPoster，可下载 PNG）；列表「生成海报」快捷操作
5. 页面与导出均不含 UID，不引入 service_role key
