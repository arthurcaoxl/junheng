# 测试环境安全验收 Checklist

## 1. 防爆破机制
- [ ] 连续输入错误产品码 5 次，确认第 6 次被阻断并提示锁定。
- [ ] 等待 15 分钟后，确认可再次尝试激活。

## 2. 并发互斥
- [ ] 设备 A 与设备 B 同时使用同一产品码发起激活。
- [ ] 确认严格只有 1 个设备成功，另一个设备返回已绑定/锁定错误。

## 3. 雷达物理脱敏
- [ ] 抓包审查 `get_coach_radar_v1` 的 JSON 响应体。
- [ ] 确认绝对不包含 `height`、`weight`、`records` 等原始敏感字段。
- [ ] 确认返回体仅包含 5 个规范字段：`camper_code`、`weight_delta`、`waist_delta`、`bmi`、`alert_level`。

## 4. 老用户兼容性
- [ ] 无码老用户进入打卡页，确认正常放行，不阻断原有打卡保存功能。
