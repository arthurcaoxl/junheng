# ADR 0001：打卡记录使用真实日期键

- 状态：已接受
- 日期：2026-10-28

## 背景

21 天打卡需要允许修改开营日，同时保留已经发生的记录，并支持旧数组数据迁移。

## 决策

`records` 使用本地日历日期 `YYYY-MM-DD` 作为键；`startDate` 只定义当前 21 天窗口，不作为记录数组下标。旧数组映射到截止迁移当天的连续 N 天。

## 影响

调整开营日不会把旧记录改写到其他真实日期；CSV 可直接导出真实日期。实现必须避免 UTC 转换造成跨日偏移，日期与迁移语义以 `docs/contracts/storage-v3.md` 为准。
